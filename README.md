# Практическая работа №8: Возможности CSS-анимации на веб-страницах

В рамках этого задания вам предстоит освоить работу с ключевыми кадрами (`@keyframes`) и свойствами анимации в CSS3 на примере интерактивной модели вращения Луны по орбите.

## 📋 Техническое задание

Ваша базовая задача — изучить видеоматериалы, сделать форк репозитория и повторить механику вращения спутника вокруг планеты, разделив разметку (`index.html`) и стили (`style.css`).

### 🛡️ Антиплагиат (Условия вариативности)
Чтобы работа была зачтена автоматическим скриптом и принята на проверку, вы **обязаны индивидуализировать** параметры анимации под свой вариант. Студенты с идентичными таймингами и траекториями к защите не допускаются.

Рассчитайте параметры по формуле: **N = количество букв в вашей Фамилии**.

1. **Скорость вращения Луны (`animation-duration`):**
   * Вместо стандартных 5 секунд из видеоурока, установите время анимации равным: `(N * 0.5) + 2` секунд.
   * *Пример для фамилии «Иванов» (6 букв): (6 * 0.5) + 2 = 5.0с. Для «Петров» (6 букв): поменяйте формулу на `+ 1.5`, чтобы получить уникальное значение.*

2. **Направление и тип сглаживания:**
   * Если ваш порядковый номер в списке группы **четный**: используйте `animation-timing-function: linear` и стандартный ход.
   * Если номер **нечетный**: используйте `animation-timing-function: ease-in-out`, а направление движения сделайте реверсивным (`animation-direction: reverse`).

3. **Задание для продвинутых разработчиков:**
   * Реализуйте дополнительную анимацию так, чтобы Земля одновременно с Луной вращалась вокруг своей собственной оси в центре экрана.

4. **Осознанность (Блок документации):**
   * В самом конце вашего CSS-файла добавьте комментарий `/* Своими словами */` и ответьте на вопросы:
     1. За счет какого свойства (или комбинации свойств) Луна уходит на задний план за Землю на 50% анимационного цикла?
     2. Какую функцию выполняет значение `infinite` в свойстве `animation`?
